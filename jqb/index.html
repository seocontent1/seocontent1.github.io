POLÍTICA DE PRIVACIDADE

Última atualização: 28 de Fevereiro de 2026

1. Informações Gerais

Esta Política de Privacidade descreve como o aplicativo JESUS QUIZ BATTLE, disponibilizado na Google Play Store, coleta, usa, armazena e protege as informações dos usuários.

O aplicativo é operado por:

2Klabs
E-mail para contato: suporte@2klabs.com.br

Ao utilizar o aplicativo, você concorda com os termos desta Política.

2. Informações Coletadas

O aplicativo pode coletar as seguintes categorias de dados:

2.1 Dados Fornecidos pelo Usuário

  • Nome ou apelido
  • Endereço de e-mail
  • Informações de login (caso utilize autenticação)

2.2 Dados Coletados Automaticamente

  • Endereço IP
  • Modelo do dispositivo
  • Sistema operacional
  • Identificadores de publicidade (Google Advertising ID)
  • Dados de uso e interação no jogo
  • Logs de erros e desempenho

2.3 Dados de Terceiros

O aplicativo pode utilizar serviços de terceiros para:

  • Análises estatísticas
  • Exibição de anúncios
  • Autenticação de usuário
  • Compras dentro do aplicativo

Esses serviços podem coletar informações conforme suas próprias políticas de privacidade.

3. Finalidade do Uso dos Dados

Os dados coletados são utilizados para:

  • Operar e melhorar o funcionamento do jogo
  • Salvar progresso do usuário
  • Fornecer suporte técnico
  • Exibir anúncios personalizados ou não personalizados
  • Prevenir fraudes e abusos
  • Cumprir obrigações legais

4. Compartilhamento de Dados

Não vendemos dados pessoais.

Os dados podem ser compartilhados apenas:

  • Com provedores de serviços necessários para o funcionamento do aplicativo
  • Para cumprimento de obrigação legal
  • Para proteção de direitos legais do desenvolvedor

5. Publicidade

O aplicativo pode exibir anúncios por meio de redes de publicidade.

Esses serviços podem utilizar cookies ou identificadores móveis para personalização de anúncios.

O usuário pode redefinir ou limitar anúncios personalizados nas configurações do dispositivo Android.

6. Segurança dos Dados

Adotamos medidas técnicas e organizacionais razoáveis para proteger os dados contra:

  • Acesso não autorizado
  • Alteração
  • Divulgação indevida
  • Destruição acidental

No entanto, nenhum sistema é completamente seguro.

7. Direitos do Usuário (LGPD)

Nos termos da Lei nº 13.709/2018 (LGPD), o usuário pode:

  • Solicitar acesso aos seus dados
  • Solicitar correção de dados incompletos ou desatualizados
  • Solicitar exclusão dos dados
  • Revogar consentimento
  • Solicitar portabilidade

Para exercer seus direitos, entre em contato pelo e-mail informado acima.

8. Retenção de Dados

Os dados serão mantidos apenas pelo tempo necessário para:

  • Cumprir as finalidades descritas
  • Atender obrigações legais
  • Resolver disputas

9. Crianças e Adolescentes

Se o aplicativo for destinado a menores de 13 anos, deve haver consentimento dos responsáveis legais conforme legislação aplicável.

Caso identifiquemos coleta indevida de dados de menores sem consentimento, os dados serão excluídos.

10. Alterações nesta Política

Esta Política pode ser atualizada periodicamente. Recomendamos revisão frequente.

Mudanças relevantes serão notificadas dentro do aplicativo.
